本文件是验收要求；最终实际结果、包哈希和来源 SHA 另随交付报告保存，不以要求代替测试结果。

- 已完成定向本机模式及原服务器 HTTPS 配置回归、目录与依赖图合成测试、发行依赖闭包回归和类型检查。
- Windows 构建、包校验和运行验证必须记录独立 D 盘目录及原有服务保护证据。
