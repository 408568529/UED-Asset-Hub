## 一、解压

最终运行包限定 Windows x64。使用与 manifest 对应、SHA-256 校验通过的 ZIP，解压到独立程序目录，完整保留 app、tools、licenses 和校验清单。当前没有可下载的 V2.5 ZIP 和整包哈希。

## 二、首次启动并选择目录

目标入口严格为“轻点击我启动.cmd”。首次向导应选择一个新的持久数据总目录，检查权限、空间、中文/空格路径、重解析点和目录冲突，确认后建立独立数据树。程序与依赖代码在数据根之外。遇到原有安装仅做预检，不覆盖或重建；原路径不存在时报错。**向导待实现。**

## 三、配置管理员及 DeepSeek

由使用者本人在目标机设置管理员和自己获准使用的 DeepSeek API Key；调用收费 API 需自行承担额度和费用。目标为 Windows DPAPI 加密静态存储；账户范围待确认，Web 保存链尚需改造。当前 DSH 默认 YAML 凭据不是加密存储，不能用于“加密已完成”的交付声明。不要把真实 Key、密码或作者配置加入源码、ZIP、日志或比赛材料。

## 四、使用与停止/再次启动

目标为同一入口完成校验、启动 Supervisor 管理的 Hub/DSH/Gateway/Proxy/GenUI，健康后自动打开实际地址。重复双击应打开同一实例；其他进程占用端口时报错。停止入口为“停止运行.cmd”，只停止本安装受管进程并验证收敛；再次启动保留配置、会话、数据和 GenUI 状态，不重复安装或输入 Key。**双击/停止入口待实现，当前无可实测的流程。**
