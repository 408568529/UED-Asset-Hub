# UED Asset Hub V2.5.2 版本变更说明

正式命名日期：2026-10-20。该版本收录本轮已经完成的微规范功能与界面修复，不新增功能或改变 V2.3 等历史标签。

1. **独立模块**：新增 `/micro-standards` 顶部一级导航，顺序为 Haldur-Design-Skill → 微规范 → 知识库；复用知识库列表、阅读器与编辑器。
2. **主题管理**：主题文件夹新建、重命名、空目录删除及规范归类；非空主题拒绝删除。管理操作要求管理员，访客可检索、阅读、下载。
3. **独立存储**：使用 `MICRO_STANDARD_ROOT`，主题 Markdown 和 `.micro-index.json` 与 Hub DATA、Haldur-Design-Skill 分开；保留完整 Metadata、正文哈希和稳定 ID。
4. **首次初始化**：沿用现有确认流程，在用户选择的全新正式资产存储位置创建 `micro-standards/` 和空索引。已有安装不重初始化，缺失目录不静默造空。
5. **历史迁移**：提供 dry-run、显式 copy、幂等与冲突检查；保留旧正文、完整元数据、ID及旧入口兼容，不自动执行服务器迁移。
6. **Agent 兼容**：沿用只读 Knowledge MCP/Gateway 检索、全文读取和引用。引用键保持兼容，链接进入独立微规范详情，防止旧副本重复收录。

同时收录本轮已确认的界面细节：主题与 Skill 文件夹操作悬停/聚焦显示；Skill 侧栏 300px；文件夹选择与展开分离；Skill 标题栏背景与正文一致。

权限不扩大；模型 Key、登录配置、运行会话和 GenUI 成果不进入 Git。本轮版本记录与提交不部署、不迁移正式数据、不构建 Windows ZIP。真实模型和 Windows 原生验收边界见 [验收报告](ACCEPTANCE.md)。
