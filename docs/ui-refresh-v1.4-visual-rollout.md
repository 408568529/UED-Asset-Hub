# UI Refresh V1.4：已确认风格扩展

基于 `ea8165f3c26461db67891d676e3f3afcd9fbda13`，仅在 `codex/visual-refresh-v1` 的持久视觉工作树开发。V1.4 是视觉任务编号，不修改应用或发行版本。

## 复用与作用域

- `knowledge-theme.css` 中已接受的颜色、字体、阅读排版和页头规则扩展到 `.asset-visual-theme`。知识列表、正文宽度、侧栏断点与折叠规则保持原实现。
- AppChrome 仅为实际的 Haldur、关联资产及对应维护入口添加页面样式标记。`/agent` 不包含该标记，继续使用原有全高度容器和隐藏 Footer 分支。
- 新的 `asset-theme.css` 适配原生／Radix 组件：控件 8px、浮层 10px、常规高度 36px；保留原控件、ref、事件、表单、文件协议和 URL。没有新增主题引擎或依赖，没有全站替换 Ant。
- 既有全局圆角兼容规则只对已选择本轮主题的 Radix portal 子树增加排除条件。未添加影响 Agent 的全局 token 或宽泛 CSS 覆盖。
- 首页仅改变暗色页头和用户指定的搜索框／两个按钮，并按追加要求对齐搜索区与最近更新／页脚的内容边缘、调淡分割线；Hero、Canvas、模块入口、最近更新数据及内容顺序保持原实现。Footer 按本轮追加要求只在首页显示。
- 知识库 `loading.tsx` 复用当前工作区壳层，采用中性灰骨架、67px 列表行和 reduced-motion；原请求与 Suspense 加载流程未改。
- AI Skill README 在知识库与独立详情入口复用现有 Markdown 安全渲染与预览／源码切换；默认文档预览，源码保留原文，版本与下载逻辑未改。
- 登录页仅新增居中容器；可用页面区域内水平／垂直居中，认证、会话、错误处理和跳转代码未变。

## 实际覆盖

Haldur 标题工具区、文件树／列表、Markdown 阅读／编辑外围、原有操作弹窗和菜单；Prompt、Skill ZIP、字体、培训的现有详情外围；对应原生维护表单及 SOP、组件规范、Vibe 产品维护表单的主题适配。已自动获得样式的知识共享详情不重复改写。

复杂资产表单保留原状态与控件，未迁移到新的 Ant 表单框架。系统设置、运行诊断、旧发布后台、DSH／Agent／GenUI 内部界面不纳入迁移。未逐项提交所有历史表单，主要动作按实际资产类型做代表性验证。
