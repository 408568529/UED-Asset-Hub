# Native Artifact Contract v1

Release-native helper builds require explicit `--mode release-native --staging-root --output-dir --temp-dir`. Output is limited to an ownership-proven staging candidate and compiler intermediates to the native build temp root. The Git checkout is never a release-native output location.

Each helper manifest is canonical UTF-8 JSON with a trailing LF and schema version 1. It retains `version`, `architecture`, and `sha256` for existing consumers; `sha256` equals `binary.sha256`. The manifest records the Asset Hub commit, source and build-script hashes, toolchain identity, build-command fingerprint, PE/import facts, and explicit passed/deferred component checks. Unknown fields, unsorted string arrays, non-x64 identity, or a binary-hash mismatch are rejected.

The frozen set has exactly six digest members and uses `ued-asset-hub-native-set-v1`: the executable and integrity manifest for each of `job-helper`, `pipe-security-adapter`, and `dpapi-helper`. `native-components.manifest.json` schema v2 binds those six hashes and sizes to the formal source commit and archive SHA-256, architecture, toolchain, and a canonical digest of all declared native source inputs. It is assembly metadata, excluded from its own digest and from the later Release canonical payload. The derived frozen directory ID is `nb2-{nativeSourceIdentity16}-{toolchainIdentity16}-{configurationIdentity16}`. A run-specific sidecar binds that native set manifest to exactly one formal run ID, source commit, and archive SHA-256; it is required before constructor assembly.

Candidate promotion first verifies the exact set, all component-to-aggregate bindings, hashes, and the derived ID; it then uses a same-volume rename to the deterministic frozen directory. Repeating an identical promotion is idempotent. Release assembly copies only the six verified members and verifies every copied hash.

Windows-native reparse, hardlink, and ADS validation is performed only by `scripts/verify-windows-native-artifact-filesystem.ps1` against an approved staging path. Cross-platform contract fixtures do not claim that evidence.
