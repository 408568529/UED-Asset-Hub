# UED Asset Hub V2.5.4 — 原生模型配置与 Skill 批量上传

日期：2026-11-03。版本演进：V2.5.3 → V2.5.4。

## 用户可见变化

- Agent 模型配置复用 DeepSeek Harness 内置「设置 → 模型」，支持提供方、模型目录、默认模型和凭据引用，不再限定外置 DeepSeek 表单。管理员配置持久化，普通用户可切换会话模型，但不能读取密钥或修改全局设置。
- Skill 上传支持文件夹内容选择，以及多个文件/文件夹一起拖入。选择文件夹内容时不保留最外层文件夹，直接合并到 Hub 当前预设目录；保留内部中文目录和文件层级。
- 同路径冲突仍需明确选择跳过或覆盖。不可读目录不会作为虚拟文件提交，空目录及 .DS_Store 跳过。HTTP 下未知上传结果可只读比较实际目标内容，不自动重传。
- Skill 管理工具栏新增「回收位置」，删除确认显示统一回收目录。删除的实体内容仍保存在 `<HALDUR_DESIGN_SKILL_RUNTIME_ROOT>/trash/<操作编号>`，不进入 Windows 系统回收站，清理前仍占磁盘空间。文件与文件夹共用这一位置。管理员仅清理已完成删除事务的回收子目录；恢复状态未解决时保留相关内容。
- 修复已安装 Windows 生产版本状态请求重复全量读取 DSH 源码造成的超时：每次启动完整验证，状态轮询复用启动身份并检查实时健康、路径及构建身份。其他环境保持原完整验证行为。

## 配置与权限边界

管理员的原生设置客户端仅适配已验证的固定 DSH 版本，未知客户端版本拒绝适配。普通用户保持原上游配置作用域，配置与凭据 RPC 仍由服务端鉴权。按 Cookie 区分客户端并禁止缓存，避免角色之间复用配置客户端。没有改变上游 loopback 身份或开放本机编辑器能力。

统一回收目录沿用现有事务存储，未更改删除、恢复或真实业务数据格式，不新增自动清理和永久删除API。服务器绝对路径仅在管理员的实时响应中返回，不向普通用户暴露，不写入发布文档。

## 验证与发布边界

本版本包含模型/代理权限、上传路径选择、生命周期验证脚本，沿用文件和目录事务回归。版本发布前从正式 main 的独立副本及锁文件安装依赖进行验证，记录见同目录 ACCEPTANCE.md。

本次是源码发布。既有 Windows LAN HTTP、浏览器 UUID 与 GenUI 启动专用部署补丁保持在原部署包中，没有回写本版本。服务器当前运行版本与这个源码标签分别记录；发布 Git 版本不会自动升级服务器。

不包含运行数据、密钥、安装ZIP、服务器账号、内部验收截图或临时构建缓存。依赖与上游组件版本不变；package.json 的内部构建版本沿用0.1.1，产品版本以文档及Git标签v2.5.4标识。
